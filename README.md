### Инструкция по эксплуатации базы данных «Пункты ГНСС п. Импилахти»



##### 1\) Назначение

Настоящая база данных создана 21.06.2026 в рамках работы над объединением информации о пунктах сети п. Импилахти в единую систему знаний. Данная база требует ежегодного обслуживания с целью поддержания актуальности данных о пунктах в местной сети.



##### 2\) О базе

База представляет собой файл GeoJSON с внутренней СК EPSG:4326 (WGS84). Координаты точек внутри представлены двумя форматами: геометрией (мультиточка с координатами Lat/Lon в десятичных градусах) и плоские прямоугольные координаты в местной системе координат.



Файл содержит следующие поля:

* fid - Int - Уникальный идентификатор внутри geojson;
* idx\_itrf - Str(4) - Уникальное четырёхзначное имя пункта на латинице, заданное в соовтетствии с ITRF;
* full\_name - Str - Полное имя пункта;
* H\_local - Float/Real - Высота пункта в местной системе **в метрах**;
* X\_local - Float/Real - Долгота пункта в местной системе **в метрах**;
* Y\_local - Float/Real - Широта пункта в местной системе **в метрах**;
* sign\_type - Str - Тип знака пункта (пирамида, сигнал, тур);
* center\_type - Str - Тип центра пункта (грунтовый, арматура);
* h\_above\_ground - Float/Real - высота знака над (под) землёй **в метрах**. Отрицательное значение высоты -> знак лежит ниже уровня земли;
* last\_observed\_year - Int - Год обновления информации о точке **в формате yyyy**;
* built\_year - Int - Год закладки точки **в формате yyyy**;
* has\_trench - Boolean - **True**/**False** наличие окопки.
* photo\_path - Str - Путь к фото-превью точки;
* note - Str - Примечание;





##### 3\) Заполнение БД

###### 3.1) Запись информации нового пункта

1. Загрузите фотографии пункта в корневую папку, назвав папку пункта в соответствии с 4-х буквенным именем как в системе ITRF («ГНСС\_Импилахти/Привязка/{idx\_itrf}/\*.png»);
2. Используя QGIS откройте проект (project.qgz), и далее включите панель Дополнительные инструменты оцифровки (Верхняя панель «Вид» -> «Панели инструментов» -> «Дополнительные инструменты оцифровки»);
3. Выберите слой «Пункты» и включите режим редактирования, далее -> «Добавить точечный объект»;
4. На открытой ранее панели «Дополнительные инструменты оцифровки» нажмите на кнопку «Включить дополнительные функции оцифровки»;
5. В открытом меню введите Долготу и Широту в десятичном формате;
6. Заполните аттрибутивную таблицу в соответствии с назначениями полей (см. п.2).



###### 3.2) Обновление информации для существующего пункта

1. Используя QGIS откройте проект (project.qgz) и выберите активным слой «Пункты»;
2. Включите режим редактирования слоя;
3. Обновите координаты, высоты пунктов, загрузите новые фотографии в соответствии с п. 3.1.1;
4. Обновите поле года данных last\_observed\_year.



##### 4\) Использование БД

1. Используя QGIS откройте проект (project.qgz) и выберите активным слой «Пункты»;
2. Убедитесь в наличии соединения с Интернетом для подгрузки базовой карты (OSM Standart);
3. На верхней панели выберите инструмент «Определить объекты» и нажмите левой кнопкой мыши на определяемый пункт. Должна открыться панель «Результат определения» с атрибутивной информацией;
4. Для просмотра галереи фотографий пункта нажмите тем же инструментов (п. 4.3) правой кнопкой мыши на пункт и выберите инструмент «Открыть галерею фото». В стандартном браузере компьютера откроется локальный сайт с галереей фотографий.
